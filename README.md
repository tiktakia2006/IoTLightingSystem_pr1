# Система освітлення з IoT (варіант 13)

**Практична робота №1 (практичні заняття 1–4)** з дисципліни «Розробка програмного забезпечення мобільних пристроїв».
Виконав: **Провальський Тарас, група ТВ-31**.

Застосунок написаний на **Kotlin + Jetpack Compose (Material 3)**.
У кожному занятті реалізовано три рівні складності: базовий, середній, просунутий.
Між рівнями можна перемикатися кнопками вгорі екрана.

## Структура

| Заняття | Пакет | Що реалізовано |
|---|---|---|
| ПЗ №1 | `practical_example_1` | «Hello World»: текст, кнопка, випадкові значення, анімація, Material Theme |
| ПЗ №2 | `practical_example_2` | Gradle, бізнес-логіка в окремому класі `LightingCalculator`, розрахунок споживання та економії |
| ПЗ №3 | `practical_example_3` | Column/Row, зображення лампи, кнопки режимів (День/Вечір/Ніч), картка `InfoCard` |
| ПЗ №4 | `practical_example_4` | Вхід і реєстрація, валідація `AuthValidator`, індикатор завантаження |


## Технічні параметри

- Kotlin 2.0.20 · Android Gradle Plugin 8.6.0 · Compose BOM 2024.06.00
- compileSdk / targetSdk 34, minSdk 26
- Логіка окремо від UI: `data/LightingCalculator.kt`, `forms/AuthValidator.kt`
